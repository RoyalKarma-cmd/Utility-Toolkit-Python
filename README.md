# Utility Toolkit Python

## Project Overview

Utility Toolkit is a menu-driven Python application that combines multiple useful utilities into a single program.

The project demonstrates the use of Python fundamentals, loops, conditions, modules, and problem-solving skills by integrating several everyday tools into one application.

This project was built as part of my Data Science and Machine Learning learning journey.

---

## Features

### 1. Calculator

Perform various mathematical operations:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Modulus (%)
* Square (^2)
* Cube (^3)
* Power
* Percentage

---

### 2. Random Number Generator

Generate a random number within a user-defined range.

Example:

```text
Enter Minimum Number: 1
Enter Maximum Number: 100

Generated Number: 57
```

---

### 3. Dice Roller

Simulates a six-sided dice roll.

Example:

```text
🎲 Roll the Dice: 4
```

---

### 4. Current Date & Time

Displays:

* Current Date
* Current Time
* Current Day
* Current Month

Example:

```text
Current Date: 13-06-2026

Current Time: 15:45:20

Current Day: Saturday

Current Month: June
```

---

### 5. Age Calculator

Calculates a user's age using their birth year.

Example:

```text
Enter Birth Year: 2005

Your Age: 21
```

---

### 6. Exit

Allows the user to safely close the application.
